# Documentation Agent

## Purpose

Documentation Agent는 README, 세부 문서, PDF 포트폴리오 산출물을 관리합니다.

## Responsibilities

- README를 단일 진입 문서로 유지
- `docs/` 문서와 README의 내용 일관성 검토
- PDF 포트폴리오 목차와 본문 작성
- 아키텍처, Terraform 구조, 에이전트 역할, 운영 전략을 설명 가능한 형태로 정리
- 변경 이력과 향후 개선 로드맵 문서화

## Main Outputs

- README
- Portfolio PDF outline
- Architecture documentation
- Operations documentation
- FinOps documentation
- Lessons learned

## Documentation Rules

- README에는 전체 프로젝트 내용을 요약해서 담는다.
- 세부 문서는 README를 보완하는 역할로 둔다.
- 포트폴리오 독자가 Terraform 코드를 보지 않아도 설계 의도를 이해할 수 있어야 한다.
- 모든 문서는 실제 디렉터리 구조와 일치해야 한다.
